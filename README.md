# Atividade-5
🎮 GameZone Retro
📌 Sobre o Projeto

O GameZone Retro é uma página promocional desenvolvida em HTML puro, criada para representar uma loja especializada em jogos e consoles clássicos.

O projeto foi desenvolvido como um desafio de HTML, com foco na utilização dos principais elementos de uma página web, mantendo o código simples, organizado e com no máximo 50 linhas.

🎯 Objetivo

Criar uma página compacta e funcional para apresentar a loja GameZone Retro, utilizando os principais conceitos básicos do HTML.

🛠️ Tecnologias Utilizadas
HTML5
Visual Studio Code
Navegador Web
📋 Elementos Implementados

O projeto possui os seguintes elementos:

Título e textos: apresentação da loja com utilização de negrito e itálico.
Lista: apresentação de consoles ou jogos disponíveis.
Navegação interna: utilização de uma âncora para navegar dentro da própria página.
Link externo: direcionamento para um site relacionado a jogos.
Imagem: imagem relacionada ao universo dos games retro.
Tabela: apresentação de produtos e seus respectivos preços.
🎮 Tema

O tema escolhido foi uma loja de games retro, destacando consoles, jogos e produtos clássicos que fizeram parte da história dos videogames.

📊 Produtos

A página apresenta uma tabela simples com pelo menos três produtos e seus preços, permitindo visualizar algumas das opções disponíveis na loja.
